# PADZ para Windows

Pads, drums, metrónomo y set list para músicos de iglesia.

## Descargar

**[⬇ Descargar PADZ para Windows](https://github.com/tg1387239-ai/PADZ-Windows/releases/latest/download/PADZ-Setup.exe)** (Windows 10 y 11, 64 bits)

1. Abrí **PADZ-Setup.exe**. Se instala solo y abre PADZ.
2. Si aparece *"Windows protegió tu PC"*: tocá **Más información → Ejecutar de todas formas**.
3. Para actualizar, instalá la versión nueva encima: tus canciones, set lists y ajustes se mantienen. PADZ te avisa cuando hay una nueva.

En el celular no hace falta instalar nada de acá: entrá a **[padz.tg1387239.workers.dev](https://padz.tg1387239.workers.dev/)** y agregala a la pantalla de inicio.
